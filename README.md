# Rambox Mobile 📱⚡

A modern, responsive multi-workspace messaging and productivity application for Android, built with Capacitor and React.

## ✨ Fitur Utama

- **Dynamic Island Navigation**: Tampilan navigasi mengambang berdesain modern dengan kontras tinggi, status aktif, dan kontrol cepat.
- **Dukungan 89+ Layanan Web & Pesan**: WhatsApp Web, Telegram, Discord, Facebook, YouTube, Gmail, Slack, Twitter/X, dan puluhan layanan lainnya.
- **WhatsApp Web Mobile Adaptive**: Tampilan single-pane responsif saat di dalam obrolan tanpa merusak halaman scan QR login.
- **Kelola Layanan Aktif**: Tambah dan hapus layanan aktif dengan mudah melalui Dynamic Island atau modal katalog.
- **Pembaruan Otomatis (OTA & In-App)**: Pengecekan pembaruan otomatis langsung dari GitHub Releases tanpa ribet.

## 🛠️ Build & Development

```bash
# Install dependencies
npm install

# Jalankan development server
npm run dev

# Build web assets
npm run build

# Sinkronisasi ke Android
npx cap sync android

# Build APK (Debug)
cd android && ./gradlew assembleDebug
```
